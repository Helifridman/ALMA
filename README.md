# EnglishQuest Israel

אפליקציית Web ללימוד אנגלית לילדים דוברי עברית (כיתות ד'–ו'), בנויה כמשחק: מסלול הרפתקה בשישה עולמות, שיעורים קצרים, שמע לכל מילה ומשפט, הסברים בעברית על כל טעות, חזרות חכמות, נקודות, הישגים ודמות מלווה מקורית.

הגרסה הראשונה עובדת **ללא שרת, ללא API key וללא הרשמה**: כל ההתקדמות נשמרת מקומית בדפדפן (localStorage), והשמע מופק ב-Web Speech API של הדפדפן.

> הקובץ הישן `index.html` (אבטיפוס חד-קובצי) הועבר ל-`legacy/prototype-v1.html` ואינו חלק מהאפליקציה.

## הפעלה מקומית

דרישות: Node.js 20 ומעלה.

```bash
npm install
npm run dev        # פיתוח: http://localhost:3000
```

גרסת ייצור (כולל Service Worker ו-PWA):

```bash
npm run build
npm run start      # http://localhost:3000
```

לפתיחה מהטלפון באותה רשת: `npm run dev -- -H 0.0.0.0` ואז `http://<כתובת-המחשב>:3000`. "הוסף למסך הבית" מתקין את האפליקציה.

## בדיקות

```bash
npm run typecheck        # TypeScript
npm run lint             # ESLint
npm test                 # Vitest: ניקוד, בדיקת תשובות, SRS, מנוע השיעור, אבחון, שמירה, ותוקף כל התוכן
npm run validate-content # רק בדיקות התוכן (ids, תשובות נכונות במסיחים, עברית/אנגלית, מילים קיימות)
npm run build && npx playwright test   # מסע משתמש מלא בדפדפן (viewport נייד)
```

ל-Playwright צריך Chromium: `npx playwright install chromium`, או `CHROMIUM_PATH=/path/to/chrome` לדפדפן קיים.

### הוספת תוכן

- מילה חדשה: שורה אחת ב-`src/content/vocabulary.ts`.
- שיעור חדש: `defineLesson({...})` בקובץ העולם המתאים, עם `ex.<type>(payload, {explanationHe, hintsHe})`. ה-ids נוצרים אוטומטית.
- עולם/יחידה: `src/content/worlds.ts`.
- `npm run validate-content` בודק שהכול תקין (תשובה נכונה קיימת במסיחים, אין כפילויות, ids של מילים קיימים, עברית/אנגלית במקומות הנכונים).

## ברירות מחדל והחלטות שתועדו

- **פנייה בלשון נקבה** בכל טקסטי הממשק וההסברים, בהתאם לבריף (המשתמשת הראשונה היא תלמידה). הוספת מצב פנייה ניטרלי/זכר היא שינוי טקסטואלי בלבד.
- **תמונות מילים**: עד שייווצרו איורים מקוריים, התמונה של כל מילה היא אמוג'י גדול (שדה `emoji`). כששדה `imageUrl` קיים הוא מקבל עדיפות. אייקוני הממשק עצמם הם SVG מקוריים, לא אמוג'י.
- **שמע**: Web Speech API; הקול נבחר אוטומטית מבין קולות אנגליים זמינים במכשיר (עדיפות ל-en-US). כשאין תמיכה מוצגת הודעה והתרגיל ניתן להשלמה. שדה `audioUrl` מאפשר להחליף להקלטות אמיתיות בלי לשנות קוד.
- **הגייה**: אין ציון הגייה אוטומטי (אין מנגנון אמין ללא שירות חיצוני). תרגיל "קראי והקליטי" מאפשר האזנה, הקלטה מקומית והשוואה עצמית; `SpeechAssessmentProvider` ב-`audio.ts` הוא נקודת החיבור לעתיד.
- **אבחון**: רמה "עוברת" כש-2/3 מהשאלות שלה נענו נכון בניסיון ראשון; נקודת הפתיחה היא הרמה הראשונה שלא עברה, מוגבלת לרמה 3 כדי שכל לומדת תעבור את יסודות בניית המשפט.
- **רצף**: החמצת יום מאפסת את המונה אבל לא מורידה XP, הישגים או מטבעות.
- **שער הורים**: קוד PIN אופציונלי; בלעדיו תרגיל כפל פשוט (מחסום לאבטיפוס, לא אבטחה).
- **נתונים**: הכול ב-localStorage תחת המפתח `englishquest-israel-v1`, עם אימות Zod בטעינה. המבנה מוכן להעברה ל-Supabase (טבלאות לפי הטיפוסים ב-`types.ts`).

## מגבלות ידועות

- אין איורים מקוריים למילים (אמוג'י כ-placeholder).
- איכות הקול תלויה בדפדפן ובמכשיר; במכשירים ישנים ייתכן שאין קול אנגלי מותקן.
- אין בדיקת הגייה אמיתית.
- אין סנכרון בין מכשירים (אין חשבון). ניקוי נתוני הדפדפן מוחק את ההתקדמות.
- התוכן מופה לרמות פנימיות 0–4 ולא נבדק מול CEFR על ידי מומחה הוראה.
- הסיפורים והדיאלוגים הם טקסט + TTS, ללא הקלטות אנושיות.

## צעדים מומלצים להמשך

1. איורים מקוריים למילים ולעולמות, וקבצי שמע מוקלטים (`audioUrl`).
2. בדיקת תוכן על ידי מורה לאנגלית ומיפוי ל-Pre-A1/A1/A2.
3. חשבון וסנכרון (Supabase) עם שמירה על מצב מקומי כברירת מחדל.
4. זיהוי דיבור דרך שרת מאובטח (ללא חשיפת מפתחות בלקוח).
5. עולמות נוספים (Past Simple מורחב, Future, קריאה ברמה A2) והרחבת מאגר המילים ל-300+.
6. מצב פנייה ניטרלי/זכר והרחבת הנגישות (קורא מסך מלא).
